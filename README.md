📧 Spam Email Classifier
🔍 Overview

This project implements a machine learning-based spam email classifier to distinguish between spam and legitimate (ham) emails using text processing and classification techniques. The system improves email filtering efficiency and reduces unwanted communication.

🚀 Features
Text preprocessing (tokenization, cleaning, normalization)
Feature extraction using TF-IDF
Multiple ML models: Naive Bayes, SVM, Random Forest
Hyperparameter tuning using GridSearchCV
Model performance comparison
🧠 Methodology
Data cleaning (duplicate removal, null handling)
Text vectorization using TF-IDF
Train-test split (70% training, 30% testing)
Model training using supervised learning
Performance evaluation using accuracy
📊 Results

The model successfully classifies spam and non-spam emails with high accuracy. Among tested models, Naive Bayes and SVM performed effectively for text classification tasks.

🛠️ Tech Stack
Python (Pandas, NumPy, Scikit-learn)
NLP (NLTK)
Visualization (Seaborn)

Email spam filtering
Cybersecurity & phishing detection
Automated email management systems
